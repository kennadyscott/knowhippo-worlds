# KnowHippo Worlds prototype

Clickable prototype of a student "pick your world" settings step for KnowHippo, and the Math learning-target map re-skinned for each world: Islands (current), Sports, Retro Lands, Next-Gen, Habitats, Boggie Lands, and Notebook (plain).

Open `index.html` in a browser, or view it on GitHub Pages. Artwork in `img/` was generated with Higgsfield.
